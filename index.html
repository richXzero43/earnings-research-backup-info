A private backup for research history.

Earnings Research Backup preserves historical stock-market research observations in the application owner's Google Drive account.

What the application does

This personal Desktop OAuth application supports backup and recovery of historical research records, including evidence, provenance and generated research reports. It uses Google Drive as a backup destination and checks data integrity during restoration.

It is a research storage tool. It does not place trades or provide a public investment service.

Access chosen by the owner

The application requests Google's drive.file permission. It accesses files and folders explicitly authorised through Google Picker, or files created by the application. It does not request unrestricted access to the owner's entire Drive.

Backup operations can run locally or through GitHub Actions. Google and GitHub provide infrastructure used by the system; the privacy policy explains how information and credentials are handled.

This website contains public application information only. It does not display research observations, backup contents or credentials, and it does not perform Google sign-in or backup operations.
