Privacy policy

For the personal Google OAuth application “Earnings Research Backup”.

Effective date: 23 November 2026

Purpose and Google Drive permission

The application is used by its owner to back up and recover historical stock-market research observations. It requests only Google's https://www.googleapis.com/auth/drive.file OAuth scope.

It accesses only files and folders explicitly authorised through Google Picker, or files created by the application. The current backup implementation checks the selected folder and backup objects for owner-only access; it does not change sharing permissions or request unrestricted Drive access.

Information used and stored

Backup data includes historical research records, source evidence, provenance, reports and backup metadata used for integrity checks and recovery. Backups are stored in the owner's Google Drive account. Backup and recovery operations upload and download this data and inspect relevant Drive file metadata and permissions.

The research system also stores evidence in a private GitHub repository and may process backup data in GitHub Actions, temporary working directories and private workflow artifacts. Local setup and recovery may process the same information on the owner's computer.

OAuth credentials

OAuth credentials are used solely to authorise application setup and backup, integrity-checking and recovery operations. Local setup saves credentials in a private profile file. For hosted operations, the owner supplies that profile through a GitHub Actions secret. Short-lived access tokens are also used by Google Picker during folder selection.

Credentials are not intended to be included in public source code, research reports or this website. Anyone with sufficient access to the owner's device, Google account or authorised GitHub workflow secrets may nevertheless be able to access the corresponding credentials or data.

Use, disclosure and service providers

Data is not sold, used for advertising, or intentionally disclosed to unrelated third parties. It is used for the owner's research backup and recovery activities.

This does not mean that no third-party infrastructure processes data. Google processes authorisation requests and Drive data, while GitHub processes repository, workflow, secret and artifact information used by the research system. Their services are subject to their respective policies: Google Privacy Policy and GitHub Privacy Statement.

Retention, deletion and revocation

The backup adapter preserves historical backup objects and does not automatically delete them. The owner controls their retention in Google Drive. Local files, GitHub evidence and workflow artifacts have separate retention and deletion controls.

Access can be revoked at any time through Google Account connections by removing this application's access. Revocation prevents subsequent authorised access using the revoked grant; it does not itself delete existing backups, local copies or GitHub records. The owner can remove those separately.

This public information website

These static HTML and CSS pages contain no analytics, tracking code, forms, cookie-setting code or external scripts. They do not collect Google credentials or display backup contents. GitHub Pages hosts this website and may process ordinary request metadata, such as IP addresses and browser information, under GitHub's policies.

The application uses a temporary local browser session during OAuth setup. This is separate from this public website.
